# DSH 真流式输出与请求上下文

2026-09-26，内部 debug 包，目标设备小米 M367FC / ARM64 / Android 17 API 37。
PythonA 直接运行内置官方 dsh，不需要 DSHA。

## 本轮行为

- 回答从生成中的真实 token 增量显示，不等整段结束，也不对完成文本模拟打字。
- 官方提供的思考内容单独折叠显示，工具卡按调用身份更新进行中/完成/失败状态。
- 对话支持标题、列表、强调、链接和代码围栏；不把模型 HTML 当作页面执行。
- 刷新最多约 30 次/秒，复用消息和文本节点；阅读旧消息不强制回到底部，可点击“最新输出”。
- 发送框上方显示本次请求状态及可展开上下文：文件、字节、脱敏、排除项、内容预览。
- “＋ 文件”搜索并添加工作区文件；“选区”加入编辑器中选中的代码。选区对应缓冲区变化后清除过期选区。
- 上下文 meter 只显示官方 ACP 返回的 `used/size`，缺少数据时显示“用量待返回”。这是上下文占用，不是账单 token；没有编造系统/工具的 token 分布。
- 补丁、批准、拒绝、撤销、活动和模型选择继续保留。生成补丁不再自动切走聊天页，以免遮住后续流式回答。
- 取消会保留已经收到的文本并停止追加，清除未批准的补丁卡与 Diff。

**范围说明：** 现有 Android ACP 请求仍各自使用独立会话。面板显示的是“本次请求上下文”，之前聊天记录不会自动发送给下一次请求；没有将此改动宣称为完整官方 Web UI 或持久会话恢复。

## 修复方式

此前打包的官方 ACP 只监听最终 `assistant/message`，没有投影实时 `assistant/chunk`。
新增小型 Node 加载适配器，使用官方 session/event 中真实 `text-delta` / `reasoning-delta`，复用原有 ACP 有序输出队列。
原始 rootfs 与官方模块磁盘内容保持不变。适配器校验被适配 ACP 模块 SHA-256：
`c7caf33cdd5768e4e9e27302731708d0bb379b07038079867b403939d6c33aba`。
未来更新该依赖需要一起更新并验证适配器，版本不符会明确启动失败，不能默默退回假流式。

最终提交消息去重；重试与内容纠正按 `messageId` 撤回对应片段；真实块编号 `blockIndex` 保留 Markdown 边界。
每条原生文本事件上限 64 KiB，适配器单段累计正文/思考上限 1 MiB；超限停止 Agent 并走错误终态。
工具展示元数据采用白名单，不转发原始工具输入输出或凭据字段。
