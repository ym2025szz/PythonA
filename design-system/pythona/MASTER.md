# PythonA UI 约定

依据本轮获批方案与 UI/UX Pro Max 的交互指导整理；这是一份项目约定，不冒称自动数据库生成结果。

- 技术栈维持 CodeMirror、原生 JavaScript/CSS、Android WebView；资源离线随 APK 提供。
- 紧凑 IDE：深浅主题共用语义颜色，Inter 界面字体、JetBrains Mono 代码字体，4/8 间距节奏和统一描边 SVG。
- 文件数据行保持紧凑（触控 28px），关键菜单操作留较大独立命中区域；禁止通过重叠命中区域伪造可触控性。
- 主要操作固定可达，低频操作进入菜单。DSH 用一个模型入口，详情逐层展开。
- 横屏短高度必须约束 grid 行最小尺寸；侧栏可滚动，工具条、发送、停止不落到键盘后。
- 编辑建议是装饰层，明确接受前不修改文档；IME、只读、旧版本与服务重启都能撤销建议。
- 模型、用量、任务终态都必须来自真实能力或事件；新会话不得沿用旧会话的上下文计数。
- 持久失败留在对应面板，输入或未保存内容不因异步响应被覆盖。
- 流式显示按帧批量刷新，复用消息节点；保留阅读位置、折叠状态和分页。
- 模型文本不作为 HTML 执行，代码块复制不执行代码；历史 Diff 不恢复批准权。
- 校验桌面/触控、深浅主题、键盘与 IME、960×320 矮屏；动画遵守减少动画设置。
